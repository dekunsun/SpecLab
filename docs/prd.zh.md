## 一页看完

| 项 | 内容 |
| --- | --- |
| 产品 | 把工业客户的材料性能规格变成一份"候选材料集 + 每个候选的证据等级 + 验证方案"的交付包 |
| 客户 | 半导体设备商或晶圆厂的工艺集成团队；自动化材料实验室的计算与合成团队 |
| 要完成的事 | "我给出器件级目标，你告诉我该先做哪几种材料、凭什么、还有什么没验证、下一步实验怎么排" |
| 最危险的失败 | 把计算得到的数字当成已验证的性能交付：规格阈值没有方法误差、估算器当筛子、DFT 值算在不稳定结构上 |
| 核心设计 | 系统只在 DFT 级证据上淘汰候选；代理指标只分级不淘汰；每个阈值带方法误差；每个候选带证据等级与"未验证项"清单；每次运行前登记预测 |
| 衡量方式 | 已知正例召回 100%；已知反例在教科书所说的阶段被淘汰；A 级产出与证据覆盖率；每候选成本与周期；XRD 质控门 |
| 现状 | v0.3：93,902 条 JARVIS 条目 → 20 个 A 级候选；37 条登记预测中 21 条成立；未运行任何语言模型；未制备任何材料 |

## 问题与用户

AI 材料发现的公开叙事以"发现了多少新材料"计数。工业客户问的是另一件事：针对我的规格，先做哪几个，证据到哪一步，还缺什么。两者之间的缺口是本产品要补的。

| 用户 | 处境 | v1 给他们什么 |
| --- | --- | --- |
| **工艺集成工程师**（主要用户）：设备商或晶圆厂，负责下一代高-k 栅介电或铁电存储氧化物的材料选型 | 文献和数据库给出成百上千个"有潜力"的化合物，没有统一的证据口径，也不知道哪些数字是算在不稳定结构上的 | 一份按证据等级排序的候选集，每项附带隙、介电常数、声子稳定性、ICSD 标记、衬底匹配，以及明确列出的"尚未验证项" |
| **自动化实验室的计算科学家**（次要用户）：把候选送进合成与表征闭环 | 需要一个可复现、可审计的筛选流程，而不是一次性脚本 | 分阶段漏斗，每阶段记录淘汰数与理由；预注册；偏差日志；可复用的 eval 题库 |
| **项目/运营负责人**：决定实验资源投向 | 实验吞吐有限，要知道每个候选的证据成本与下一步实验成本 | 阶段门、每候选成本、周期估计、XRD 质控门 |

## 两层规格：客户语言与模型语言

| 层 | 内容 | 谁负责 |
| --- | --- | --- |
| 器件级目标 | EOT、栅漏电流、剩余极化、耐久、保持、热预算 | 客户给出；本产品记录、不计算 |
| 材料级代理指标 | 带隙、介电常数、凸包距离、组成约束、与 Si 的带阶、可沉积性 | 本产品筛选；每项写明映射、容差与来源 |

产品必须明确说明：代理指标不等于器件指标。界面层 SiOx 贡献 0.4 到 0.7 nm 的 EOT，材料级 k 目标要留余量；耐久、保持、唤醒无法由计算预测，只能留给实验。

## 设计原则（由 v0.1 到 v0.3 的发现推出）

| 发现（已登记、已运行） | 数据 | 对应设计 |
| --- | --- | --- |
| 估算器不能当筛子 | Clausius-Mossotti 对 765 个有 DFPT 值的氧化物召回率 0.45；按预注册规则把阈值降到满足 0.9 召回时，保留 67% 候选 | 只有 DFT 级证据才允许淘汰；估算值只作标记（FR2） |
| 数据库字段不能默认可信 | JARVIS 的 ehull 字段把单斜 HfO2 标为 1.78 eV/atom above hull | 凸包由生成能重算；每个数据源列出不可用字段（FR5） |
| 阈值必须带方法误差 | DFPT 对实验 MARD 16%，TBmBJ 约 15%；ZrO2 在 JARVIS 的 TBmBJ 带隙 4.21 eV，比实验低 1.6 eV | 通过线 = 目标 × (1 − 方法误差)，运行前声明；被误杀的已知材料作为代价公开记录（FR3） |
| DFT 值可能算在不稳定结构上 | 5 个 DFPT k > 100 的 A 级候选全部有虚频；再查全部 29 个，又有 4 个 k 在 28 到 73 之间的候选不稳定 | 声子检查是 A 级的必要条件；不稳定者降级并标注"DFPT 算在动力学不稳定结构上"（FR4） |
| 证据覆盖决定产出上限 | 稳定氧化物中只有 10.6% 有 TBmBJ 带隙 | 每份交付物报告证据覆盖率，不只报候选数（FR7） |
| 预测要先登记 | 37 条预测，21 条成立，12 条失败，4 条无法判读；每条失败记录方向 | 每次阈值变化、每个新阶段先登记预测再运行（FR9） |

## 衡量方式与目标

| 指标 | 定义 | 目标 | v0.3 实际 |
| --- | --- | --- | --- |
| 正例召回 | 已知工业材料通过规格的比例 | 100%，或每个漏网都有登记的解释 | 6/6（v0.1）；v0.2 中 ZrO2 因 TBmBJ 误差漏网，已提前声明 |
| 反例淘汰阶段准确率 | 已知反例在教科书所说阶段被淘汰的比例 | 100% | 7/7（v0.1）；6/6（v0.2） |
| A 级产出 | 两项关键指标均有 DFT 级证据且声子稳定的候选数 | 10 到 50 | 20 |
| 证据覆盖率 | 稳定氧化物中有 TBmBJ 带隙 / 有 DFPT 介电的比例 | 报告，不设目标 | 10.6% / 约 1.5% |
| 不稳定结构检出 | A 级候选中声子不稳定的比例 | 报告 | 9/29 |
| 计算成本 | 每次完整运行的机时 | 单机 CPU 一小时内 | 漏斗 75 s；声子 29 个约 10 min；MACE 松弛 35 个约 5 min |
| XRD 质控门 | 单相干净 / 应变单相 / 两相的准确率 | 高于带晶格精修的经典基线：100% / 65% / 50% | 基线已测 |

北极星：客户拿到的候选集里，每一个数字都能回答"证据到哪一步"。

## 模型准入（FR12）

任何语言模型在进入"文献抽取、合成路线、实验计划"环节前，须在 XRD 保留集（60 题，本地）上运行一次，各档与公开集成绩差距在 10 个百分点以内且不低于带晶格精修的经典基线；有一档不达标才追加两次。弃答计为覆盖率而非错误。每次模型更新重测。LiveLab 1.0 的结论直接沿用：证据不够时由系统给出"无法验证"，不由模型决定。

## 运营模型

| 项 | 内容 |
| --- | --- |
| 阶段门 | 组成 → 稳定性 → 带隙 → 介电 → 声子 → 衬底 →（待建）带阶 / 反应 / 前驱体；每个门记录淘汰数与理由 |
| 周期 | 从规格冻结到候选档案：当前一台 CPU 机器一小时内 |
| 实验侧假设 | 自动化实验室每天数百样品时，20 个 A 级候选的组合库沉积与 XRD 初筛约一到两天；瓶颈在相鉴定质控，不在沉积 |
| 数据管道 | 每次运行写入 results/，含无效运行；题库与答案分离；保留集本应只存哈希，但曾误提交（2026-10-22 更正，见登记） |
| 成本 | 计算近乎零；模型 eval 按 token 计费（见提案附录） |

## 非目标

- 不宣称发现新材料。本版本只处理数据库中已有结构。
- 不替代 DFT 或实验。产品的工作是组织证据、暴露缺口、排优先级。
- 不做器件级预测。

## 风险与开放问题

| 风险 | 应对 |
| --- | --- |
| Shannon 极化率表未核对 | 估算器已降为标记；核对后决定保留或退役 |
| TBmBJ 覆盖率低，A 级列表受数据而非物理限制 | 下一版用 MLIP 或 HSE 子集补带隙；报告覆盖率 |
| 衬底匹配搜索过于宽松 | 只在面积小时报告；考虑收紧面积上限 |
| 规格阈值对单个材料的不确定度不敏感（ZrO2 案例） | v0.4 考虑按材料不确定度的规则；需登记 |
| 语言模型准入尚未运行 | 等 API 密钥；按登记流程跑 |
